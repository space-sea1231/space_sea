# 🎯 网页智能点击器 - 安装指南

## 📦 安装方法

### 方法一：直接下载安装（推荐）

1. **下载扩展文件**
   - 点击右上角绿色 `Code` 按钮
   - 选择 `Download ZIP`
   - 解压到任意文件夹

2. **安装到Chrome**
   - 打开Chrome浏览器
   - 地址栏输入：`chrome://extensions/`
   - 开启右上角的"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择解压后的 `browser-extension` 文件夹

3. **开始使用**
   - 工具栏会出现扩展图标
   - 点击图标打开控制面板
   - 按照界面提示使用

### 方法二：Git克隆安装

```bash
# 克隆仓库
git clone https://github.com/您的用户名/网页智能点击器.git

# 进入目录
cd 网页智能点击器/browser-extension

# 按照方法一的步骤2-3安装
```

## 🎯 快速上手

### 基本使用
1. **选择点击区域** - 按 `Ctrl+Shift+3` 或点击"选择区域"
2. **开始点击** - 按 `Ctrl+Shift+1` 或点击"开始点击"
3. **停止点击** - 再按 `Ctrl+Shift+1` 或按 `Ctrl+Shift+2`

### 快捷键
- `Ctrl+Shift+1` - 开始/停止点击
- `Ctrl+Shift+2` - 紧急停止
- `Ctrl+Shift+3` - 选择点击区域

### 速度设置
- **极速(1ms)** - 1000次/秒，适合高频测试
- **超快(5ms)** - 200次/秒，适合游戏挂机
- **快速(10ms)** - 100次/秒，适合一般自动化
- **正常(50ms)** - 20次/秒，适合模拟人工操作

## ❓ 常见问题

### Q: 为什么点击没有效果？
A: 请确保：
- 已选择正确的点击区域
- 目标网页元素可以被点击
- 没有被其他软件阻止

### Q: 如何卸载？
A: 在 `chrome://extensions/` 页面找到扩展，点击"移除"

### Q: 支持其他浏览器吗？
A: 支持所有基于Chromium的浏览器（Edge、360、QQ浏览器等）

### Q: 会被网站检测吗？
A: 使用随机延迟可以降低被检测的风险，但请遵守网站服务条款
