# 🎯 网页智能点击器

真正的网页后台点击解决方案 - 不影响真实鼠标，支持1ms超高速点击

## ✨ 主要功能

### 🚀 超高速点击
- **1ms极速模式** - 高达1000次/秒的点击速度
- **智能随机延迟** - 模拟真实用户操作，避免检测
- **四种快速预设** - 极速、超快、快速、正常一键应用

### 🎯 精确控制
- **区域选择** - 拖拽选择任意点击区域
- **随机坐标** - 在选定区域内随机点击
- **实时统计** - 显示点击次数和速度

### 🔄 智能间歇模式
- **防检测设计** - 连点+暂停的智能循环
- **四种间歇预设** - 快速、标准、长时、保守模式
- **实时状态显示** - 清晰显示当前阶段和剩余时间
- **自定义配置** - 灵活调整连点和暂停时长

### ⌨️ 快捷键操作
- **Ctrl+Shift+1** - 开始/停止点击
- **Ctrl+Shift+2** - 紧急停止
- **Ctrl+Shift+3** - 选择点击区域

### 🛡️ 真正的后台点击
- **不移动真实鼠标** - 完全后台操作
- **绕过安全限制** - 直接操作DOM元素
- **支持所有网页** - 兼容各种网站和应用

## 🔧 安装使用

### 安装方法
1. 下载扩展文件
2. 打开Chrome扩展管理页面 (`chrome://extensions/`)
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择扩展文件夹

### 使用步骤
1. **选择区域** - 点击"选择区域"按钮，拖拽选择点击区域
2. **选择模式** - 普通模式或智能间歇模式
3. **快速预设** - 使用预设按钮快速应用常用配置
4. **开始点击** - 点击"开始点击"或使用快捷键 `Ctrl+Shift+1`
5. **实时监控** - 查看状态显示框了解当前运行状态
6. **停止点击** - 再次按快捷键或点击"停止点击"
