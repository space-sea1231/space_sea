> 最近公共祖先LCA（Lowest Common Ancestor）

## 定义

在一颗树形结构中，两个结点$x$和$y$的公共祖先中深度最大的一个（有且只有一个）。

## LCA的实现

### 方法1：暴力染色

1.  从$x$往上走到根节点，并沿途染色；
2.  从$y$往上走到根节点，沿途遇到的第一个染色节点即为$x$和$y$的`lca`，记为`lca(x,y)`；时间复杂度为$O(n)$。

### 方法2：倍增求LCA

1.  预处理`dp[i][j]`表示点$i$向上走$2^j$步到达的结点编号：

1.  `dp[i][j]=dp[dp[i][j-1]][j-1]`；
2.  初始状态：`dp[i][0]=fa[i]`；
3.  注意先转移再递归；
4.  时间复杂度：$O(n\log n)$。

2.  询问一对$(x,y)$的`lca`：

1.  约定点$y$深度更大，若`dep[y]<dep[x]`，则`swap(x,y)`；
2.  点$y$向上倍增跳跃至与$x$的深度一致，并判断是否重合；
3.  $x$和$y$一起向上倍增跳跃，不能重合，最后再走一步即为`lca`；
4.  单次询问$O(\log n)$。

## LCA的应用

### 求树上两点之间的距离

`dis[x]+dis[y]-2*dis[lca(x,y)]`，其中`dis[x]`表示根节点到点$x$的距离。

树上两点的距离与根节点的选取无关。

树上两点的`lca`与根节点的选取有关。

树上三节点$x,y,z$两两求`lca`得到的点不超过两个。

## 例题

### P3379 【模板】最近公共祖先（LCA）

模板。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long

const int N=7e5+5;
int n,m,s,dp[N][25],dep[N];
vector<int>nbr[N];

void pre_lca(int cur,int fa)
{
	dp[cur][0]=fa;
	dep[cur]=dep[fa]+1;
	for(int i=1;(1<<i)<=dep[cur];i++)
		dp[cur][i]=dp[dp[cur][i-1]][i-1];
	for(int i=0;i<nbr[cur].size();i++)
	{
		int nxt=nbr[cur][i];
		if(nxt!=fa)
			pre_lca(nxt,cur);
	}
	return ;
}

int lca(int x,int y)
{
	if(dep[x]>dep[y])
		swap(x,y);
	for(int i=20;i>=0;i--)
		if(dep[x]<=dep[dp[y][i]])
			y=dp[y][i];
	if(x==y)
		return x;
	for(int i=20;i>=0;i--)
		if(dp[x][i]!=dp[y][i])
			x=dp[x][i],y=dp[y][i];
	return dp[x][0];
}

signed main()
{
	ios::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);
	cin>>n>>m>>s;
	for(int i=1;i<=n-1;i++)
	{
		int u,v;
		cin>>u>>v;
		nbr[u].push_back(v);
		nbr[v].push_back(u);
	}
	pre_lca(s,0);
	while(m--)
	{
		int x,y;
		cin>>x>>y;
		cout<<lca(x,y)<<"\n";
	}
	return 0;
}
```

时间复杂度：$O(n \log n+m \log n)$。

### P5836 [USACO19DEC] Milk Visits G

#### 题意

给定一棵树，点权为`G`或`H`，有$m$次询问，每次询问路径上是否有特定点权。

#### 方法1

1.  点权转化为$0$或$1$，维护`dis[i]`代表根节点到$i$的距离。
2.  维护`dep[x]`表示$x$的深度。
3.  对于每次询问，若`dis[a]+dis[b]-2*dis[lca]+w[lca]==dep[a]+dep[b]-2*dep[lca]`成立，说明路径全$1$，若上式结果为$0$，说明路径全$0$。

#### 方法2

1.  并查集，若一条边的两个权值相同，`unionn`。
2.  若一条路径上的点权相同，则两个端点一定在同一集合，若该集合的权值与询问不一致，输出`0`，否则输出`1`。

#### 方法3

1.  维护`dp[i][j]`表示点$i$向上跳$2^j$步到达点的编号。
2.  维护`yes[i][j][0/1]`表示点$i$向上跳$2^j$步是否有权值为`0`或`1`的点。
3.  `yes[i][j][0]=yes[i][j-1][0]|yes[dp[i][j-1]][j-1][0]`，`yes[i][j][0]=yes[i][j-1][0]|yes[dp[i][j-1]][j-1][0]`。
4.  初始状态：`dp[i][0]=fa[i]`，`yes[i][0][w[fa]]=1`。
5.  对于一组询问$(a,b)$，$a$倍增跳$lca$，$b$倍增跳$lca$，检查过程中是否有询问的点权。

### CF519E A and B ans Lecture Rooms

#### 题意

给定一棵树，$m$次询问，每次询问到达$A,B$距离相等的点数。

#### 分析

1.  若$A$到$B$的距离为奇数，答案为$0$。
2.  第一大类：中间位置的点就是$lca$，$lca$儿子节点中包含$A$和$B$的子树剔除，其余均为答案。
3.  第二大类：中间位置的点$x$不是$lca$，约定深度较大的点为$B$，找到$B$向上走一步的点$p$，`siz[x]-siz[p]`即为答案。
4.  特殊情况：$A=B$，直接输出$n$。
5.  从$lca$走到$x$的步数为：`(dep[B]-dep[A])/2`。

### P8972『GROI-R1』 一切都已过去

1.  只有小数部分有$2$和$5$相乘，才可能变成整数。
2.  总的小数位数应该是所有路径上的边权的小数点之和$cnt1$。
3.  一个$2$和$5$可以抵消一个小数点数位。
4.  将边权当作整数预处理，并分解$2$和$5$的数量。
5.  若路径$x \to y$的`min(cnt2,cnt5)>=cnt1`，那么路径乘积为整数。
6.  维护`dis1[i]`表示根节点到点$i$的总的小数点数位，`dis2[i]`表示根节点到$i$的路径上的质因数$2$的个数，`dis5[]`同理。
7.  则`cnt1=dis1[x]+dis1[y]-2*dis1[lca(x,y)]`，$cnt2,cnt5$同理。
8.  若边权或点权为$0$，则$2$和$5$的数量设为极大值。

### CF379F New Year Tree

#### 暴力

每操作一次，跑树的直径一次。

时间复杂度$O(nm)$。

#### 优化

1.  每次操作，树的直径要么不变，要么加$1$。
2.  树的直径更新时，一定是新节点取代了$1$个树的直径的端点。
3.  对于每次新加的结点`z=n+1`，计算`d1=dis(x,z)`，`d2=dis(y,z)`。
4.  对于新加的结点 `n+1`和 `n+2`，倍增更新`dp[i][j]`。

时间复杂度：$O(m\log n)$。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e6+6;
vector<int> nbr[N];
int n=4,T,len=2,x=2,y=3;
int dp[N][25],dep[N];
void pre_lca(int cur,int fa){
    dp[cur][0]=fa;
    dep[cur]=dep[fa]+1;
    for(int i=1;(1<<i)<=dep[cur];i++)
        dp[cur][i]=dp[dp[cur][i-1]][i-1];
    for(int i=0;i<nbr[cur].size();i++)
        if(nbr[cur][i]!=fa)
            pre_lca(nbr[cur][i],cur);
    return ;
}
int lca(int x,int y){
    if(dep[x]>dep[y])swap(x,y);
    for(int i=20;i>=0;i--)
        if(dep[x]<=dep[dp[y][i]])
            y=dp[y][i];
    if(x==y)
        return x;
    for(int i=20;i>=0;i--)
        if(dp[x][i]!=dp[y][i])
            x=dp[x][i],y=dp[y][i];
    return dp[x][0];
}
void update(int cur,int fa){
    dep[cur]=dep[fa]+1;
    for(int i=1;(1<<i)<=dep[cur];i++)
        dp[cur][i]=dp[dp[cur][i-1]][i-1];
}
int getdis(int x,int y){
	return dep[x]+dep[y]-2*dep[lca(x,y)];
}
int main(){
	ios::sync_with_stdio(false);
	cin.tie(0);
	cout.tie(0);
	cin >> T;
	for(int i=2;i<=n;i++){
		nbr[1].push_back(i);
		nbr[n].push_back(1);
	}
	pre_lca(1,0);
	while(T--){
		int ff;
		cin >> ff;
		dp[++n][0]=ff;
		update(n,ff);
		int xx=getdis(n,x);
		int yy=getdis(n,y);
		if(xx>len)
			len=xx,y=n;
		if(yy>len)
			len=yy,x=n;
		dp[++n][0]=ff;
		update(n,ff);
		xx=getdis(n,x);
		yy=getdis(n,y);
		if(xx>len)
			len=xx,y=n;
		if(yy>len)
			len=yy,x=n;
		cout << len << "\n";
	}
}
```
