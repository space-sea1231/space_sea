## 权值线段树

指线段树管辖一段值域。

### P1637 三元上升子序列

#### 分析

1.  $(i,j,k)$不一定连续。
2.  枚举中间的下标$j$，统计$j$之前的小于$a_j$的元素个数$cnt1$，统计$j$之后的大于$a_j$的元素个数$cnt2$，那么以$j$为中间元素的三元组数量$=cnt1\times cnt2$。
3.  用权值线段树维护即可。

#### 主函数代码（1）

```cpp
signed main()
{
	cin>>n;
	for(int i=1;i<=n;i++)
		cin>>a[i];
	for(int i=1;i<=n;i++)
	{
		l[i]=query(1,1,1e5,1,a[i]-1);
		update(1,1,1e5,a[i],a[i],1);
	}
	memset(tr,0,sizeof tr);
	for(int i=n;i>=1;i--)
	{
		r[i]=query(1,1,1e5,a[i]+1,1e5);
		update(1,1,1e5,a[i],a[i],1);
		sum+=l[i]*r[i];
	}
	cout<<sum;
	return 0;
}
```
