将$1\sim n$个自然数放到$1\sim n$的位置，其中$i$不在位置$i$，求方案数。

## DP思想

### 定义状态

$dp_i$表示前$i$个位置错位排序的方案数。

### 状态转移方程

情况一：前$i-1$个数，已经错位排序，将元素$i$与前$i-1$个位置的任一元素对调形成错位，贡献为$(i-1)\times dp_{i-1}$。

情况二：前$i-1$个数，恰好有$1$个位置$j$不错位，将元素$i$与元素$j$对调，则贡献为$1\times dp_{i-2}$，$j$的可能性有$i-1$种，总贡献为$(i-1)\times dp_{i-2}$。

其余重复算过，不满足。

因此$dp_i=(i-1)\times (dp_{i-1}+dp_{i-2})$。

### 初始状态

$dp_1=0,dp_2=1$。

### 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N=25;
int n,dp[N];

signed main()
{
    n=read();
    dp[2]=1;
    for(int i=3;i<=n;i++)
        dp[i]=(i-1)*(dp[i-1]+dp[i-2]);
    write(dp[n]);
    return 0;
}
```
